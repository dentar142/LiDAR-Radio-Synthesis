# 真实问题样例与方法解释

本文档只使用已有项目截图，不使用概念图，也不把不同版本的截图伪装成严格控制变量实验。

## 1. LiDAR 降面后的几何问题

![LiDAR 降面审阅结果](../figures/real/lidar_direct_regularization_planar5deg.png)

这张图来自 `openmesh-1over80-v63` 的 planar-5deg 审阅结果。模型虽然降低了面数，但表面仍然存在碎片化、局部凹凸、细小部件混杂和不稳定边界。

问题不只是“面太多”，而是降面算法通常只根据局部几何误差或三角形数量做优化，并不知道哪些三角面实际上属于同一面墙、同一片玻璃或同一个屋顶。因此，直接 decimation 可能把一个物理平面保留成多个法向不一致的小片，也可能在建筑边缘产生锯齿和形变。

这会进一步影响法线计算、射线传播、遮挡判断、建筑边缘效应和材质赋值。对于无线电仿真，错误的表面法线和边界比单纯的面数增加更危险。

## 2. 语义分割如何帮助重构

![V6-r2 建筑掩膜](../figures/real/v6r2_building_mask_alignment.png)

这张图来自 V6-r2 的建筑排除掩膜。它说明建筑可以先作为独立空间对象从地面层中分离出来，之后再对每栋楼的墙面、屋顶和局部部件进行处理。

语义分割的作用不是简单给每个三角面换颜色，而是提供结构化约束：

```text
楼体语义       -> 建筑对象边界
墙面语义       -> 共面区域和立面方向
屋顶语义       -> 屋顶平面和高度层级
玻璃语义       -> 连通幕墙区域和统一材质
道路/水体/植被 -> 独立地面层
```

有了这些类别，重构过程可以先在“建筑部件或表面连通域”层面确定形状，再把结果映射回内部三角面，而不是让每个三角面独立决定自己的几何和材质。

## 3. 地面和建筑必须分层

![V6-r2 地面材质审阅](../figures/real/v6r2_ground_material_review_preview.jpg)

这张图来自 V6-r2 的实际地面材质审阅结果。黑色为沥青，蓝色为水体，绿色为植被，剩余非建筑区域为石头，白色区域为建筑排除区域。

如果没有建筑排除掩膜，地面标注可能进入建筑内部，导致道路穿楼、植被覆盖建筑底面或地面材质错误附着到墙体。分层处理可以把地面材质和建筑立面材质分开管理。

## 4. 材质不能逐三角面独立判断

![组件纹理蒙太奇](../figures/real/v54_component_95361_uv_montage.jpg)

这张图来自 V54 组件纹理审阅结果。纹理中存在重复投影、光照差异、反射和局部遮挡，直接进行三角面级分类容易使同一块玻璃或墙面出现多种标签。

因此，本方法采用“连通域级语义融合 -> 部件级材质决策 -> 三角面标签传播”的顺序。材质边界由建筑结构和语义连通性决定，纹理只作为证据之一。

## 5. 预期效果和真实验证指标

当前截图证明的是问题和已有处理证据，不代表新算法已经完成定量对比。后续实现应在相同输入、相同坐标和相同参数下比较：

- 平面拟合残差和法线方差是否下降；
- 建筑轮廓 IoU 和边界偏移是否改善；
- 退化三角形、孤立碎片和异常法线数量是否减少；
- 同一连通域的材质标签熵是否下降；
- 建筑内部地面误标是否为零；
- Blender/GLB 导入后的拓扑、坐标和材质槽是否稳定。

因此，方法的核心不是“把 LiDAR 模型简单变低模”，而是：

> 先用语义分割识别建筑特性和表面连通域，再用工程轮廓与 LiDAR 高度信息重构规整几何，最后进行部件级材质映射。
